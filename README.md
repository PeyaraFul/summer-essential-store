



# ☀️ Summer Essential Store

Summer Essential Store is a modern, responsive e-commerce web application designed to help users discover and purchase summer-related products through a clean, intuitive, and user-friendly shopping experience.

## 📖 Project Overview
<img width="1918" height="937" alt="image" src="https://github.com/user-attachments/assets/61397846-c3fe-4106-9590-8f577034f0ec" />


Summer Essential Store is a responsive e-commerce platform focused on summer essentials. Users can browse products, view detailed information, manage their profiles, and enjoy a seamless shopping experience across desktop, tablet, and mobile devices.

The project demonstrates modern frontend development practices, responsive design principles, reusable component architecture, and user-focused UI/UX design.

* Fully responsive design
* Modern and intuitive user interface
* Product browsing and exploration
* Product details page

* Interactive navigation and user experience

## ⚙️ Installation & Setup

### Clone the Repository

```bash
git clone https://github.com/PeyaraFul/summer-essential-store.git
```

### Navigate to Project Directory

```bash
cd summer-essential-store
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
